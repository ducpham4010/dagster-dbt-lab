# Quy trình Debug dbt ETL Project - Troubleshooting Guide

## 📋 Tổng quan

Tài liệu này mô tả chi tiết quy trình debug và giải quyết lỗi `ORA-00942: table or view does not exist` khi khởi tạo dbt ETL project từ bảng `source_customers_test_dbt` đến `target_customers_test_dbt`.

## 🚨 Lỗi ban đầu

### Triệu chứng
```bash
(venv) D:\aml-devops\mylabs\dbt-project\aml_transaction_pipeline>dbt run
05:20:11  Running with dbt=1.10.17
05:20:21  1 of 2 ERROR creating sql view model ofsaafccm.stg_customers ................... [ERROR in 0.80s]
05:20:21  2 of 2 SKIP relation ofsaafccm.dim_customers ................................... [SKIP]

Failure in model stg_customers (models\staging\stg_customers.sql)
Database Error in model stg_customers (models\staging\stg_customers.sql)
ORA-00942: table or view does not exist
```

### Nguyên nhân
- Bảng `source_customers_test_dbt` chưa tồn tại trong database
- dbt không thể tìm thấy source table để thực hiện ETL

## 🔍 Quy trình Debug từng bước

### Bước 2: Kiểm tra compiled SQL

**Lệnh thực hiện:**
```bash
cd aml_transaction_pipeline && type target\compiled\aml_transaction_pipeline\models\staging\stg_customers.sql
```

**Kết quả phát hiện:**
```sql
with source_data as (
    select 
        customer_id,
        full_name,
        phone,
        created_at
    from raw_data.source_customers_test_dbt  -- ❌ Sai schema
)
```

**Vấn đề:** dbt đang tìm bảng ở schema `raw_data` thay vì `ofsaafccm`

### Bước 3: Sửa lỗi cấu hình source schema

**File cần sửa:** `models/staging/schema.yml`

**Thay đổi:**
```yaml
# ❌ Trước khi sửa
sources:
  - name: raw_data
    description: "Raw source tables"
    tables:
      - name: source_customers_test_dbt

# ✅ Sau khi sửa  
sources:
  - name: raw_data
    description: "Raw source tables"
    schema: ofsaafccm  # Chỉ định schema chính xác
    tables:
      - name: source_customers_test_dbt
```

### Bước 4: Tạo bảng source và dữ liệu mẫu

#### 4.1 Tạo setup script SQL

**File:** `setup/01_create_tables_and_data.sql`
```sql
-- 1. Tạo bảng source
CREATE TABLE source_customers_test_dbt (
  customer_id   NUMBER GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
  full_name     VARCHAR2(200) NOT NULL,
  phone         VARCHAR2(20),
  created_at    TIMESTAMP DEFAULT SYSTIMESTAMP NOT NULL
);

-- 2. Tạo bảng target (sẽ được dbt populate)
CREATE TABLE target_customers_test_dbt (
  customer_id   NUMBER,
  full_name     VARCHAR2(200) NOT NULL,
  phone         VARCHAR2(20),
  created_at    TIMESTAMP
);

-- 3. Thêm dữ liệu mẫu
INSERT INTO source_customers_test_dbt (full_name, phone) VALUES 
('Nguyen Van A', '0901234567'),
('Tran Thi B', '0912345678'),
('Le Van C', '0923456789'),
('Pham Thi D', NULL),
('Hoang Van E', '');

COMMIT;
```

#### 4.2 Tạo dbt macro để setup

**File:** `macros/setup_table.sql`
```sql
{% macro setup_source_table() %}
  {% set sql %}
    CREATE TABLE source_customers_test_dbt (
      customer_id   NUMBER GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
      full_name     VARCHAR2(200) NOT NULL,
      phone         VARCHAR2(20),
      created_at    TIMESTAMP DEFAULT SYSTIMESTAMP NOT NULL
    )
  {% endset %}
  
  {% do run_query(sql) %}
{% endmacro %}
```

**File:** `macros/insert_data.sql`
```sql
{% macro insert_sample_data() %}
  {% set sql %}
    INSERT INTO source_customers_test_dbt (full_name, phone) VALUES ('Nguyen Van A', '0901234567')
  {% endset %}
  {% do run_query(sql) %}
  
  -- Thêm các records khác...
  
  {% do run_query("COMMIT") %}
{% endmacro %}
```

#### 4.3 Thực thi setup

```bash
# Tạo bảng
cd aml_transaction_pipeline && dbt run-operation setup_source_table

# Kết quả: ORA-00955: name is already used by an existing object
# → Bảng đã tồn tại, OK!

# Thêm dữ liệu
cd aml_transaction_pipeline && dbt run-operation insert_sample_data
```

## 🎯 Tóm tắt các vấn đề và giải pháp

### Vấn đề 1: Source schema không đúng
**Triệu chứng:** dbt tìm bảng ở `raw_data.source_customers_test_dbt`
**Giải pháp:** Thêm `schema: ofsaafccm` vào source definition

### Vấn đề 2: Bảng source chưa tồn tại
**Triệu chứng:** `ORA-00942: table or view does not exist`
**Giải pháp:** Tạo bảng bằng dbt macro hoặc SQL script

### Vấn đề 3: Thiếu dữ liệu test
**Triệu chứng:** Bảng rỗng
**Giải pháp:** Insert dữ liệu mẫu bằng dbt macro
